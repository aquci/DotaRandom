# DotaRandom

Generate random Dota 2 item builds.

## Features

- Physical builds
- Magical builds
- Fully random builds
- Cross-platform
- CMake support

## Build

Linux

''git clone https://github.com/aquci/DotaRandom.git
cd DotaRandom

cmake -B build
cmake --build build''

./build/DotaRandom

Windows

git clone https://github.com/aquci/DotaRandom.git
cd DotaRandom

cmake -B build
cmake --build build

.\build\Debug\DotaRandom.exe
